Facial recognition authentication for Odoo login page.

Allows users to authenticate using their camera instead of
email/password.

Installation
============

**Requirements:**

- Face recognition service from:
  https://github.com/out-of-reality/facial-auth-service

Configuration
=============

**Setup:**

1. **Install Face Recognition Service**

   .. code:: bash

      git clone https://github.com/out-of-reality/facial-auth-service.git

   Follow setup instructions in that repository.

2. **Configure Users**

   - Go to Settings → Users → Edit user
   - Upload a clear frontal photo in Avatar field
   - Facial encoding generates automatically

3. **Test**

   - Go to login page → "Log in FaceID"
   - Allow camera access and capture face

Usage
=====

**How to use:**

1. Click "Log in FaceID" on the login page
2. Allow camera access
3. Position your face and click "Capture"
4. System authenticates and redirects to main app
